# Emberfall: The Emberwild Saga — reconstruction specification

## 1. Build objective

Build a complete, single-player, party-based fantasy RPG that a player can start by opening `index.html`. The player leads **one company of up to six adventurers** through a late-1980s “gold box”-style game: walk a town or dungeon in first person, cross the wilderness on a painted regional map, and resolve encounters on a separate isometric tactical board. Use second-edition-style THAC0, descending armor class, memorized spells and class-specific advancement. Do not substitute a modern d20 system, a text adventure, or real-time action combat.

The core loop is **choose adventure → assemble company → obtain commissions and supplies in town → explore, fight and recover treasure → return to report, rest and train → carry the company on to another adventure**. Completing a module is a playable outcome, not a credits screen that destroys the save. A fallen party can load a save or return to the title.

**Scope of the reference:** repository snapshot `a1e0a21`. The four hand-written adventures are the named *Emberwild Saga*, not the entire game. The chooser also offers fifty deterministic adventures for levels 1–20. The loaded data and game behavior, rather than the shorter feature list in `README.md`, define parity. If working from the reference files, retain their IDs, authored maps, tables, encounter text and generation order; the examples below explain how those data must behave. The implementation milestones are a suggested order of work, not alternative release scopes.

**Implementation guide:** [Runtime and data contracts](#2-runtime-layout-and-boundaries) · [Screens and input](#3-player-flow-party-and-interface) · [Rules and resources](#4-rules-and-resources) · [Exploration](#5-first-person-exploration-and-encounters) · [Wilderness](#6-wilderness-travel) · [Combat](#7-tactical-combat) · [Adventure content](#8-adventure-content-and-campaign-progression) · [Rendering and layout](#9-rendering-maps-journals-and-layout) · [Saves](#10-saving-and-resuming) · [Build order and acceptance checks](#11-implementation-sequence-and-verification).

### Delivery constraints

- Ship `index.html`, `css/style.css`, plain JavaScript under `js/`, a player-facing `README.md`, and the MIT `LICENSE` (retain the reference copyright notice). Describe the game as an unofficial, non-commercial fan project, not an endorsed tabletop or licensed computer-game product.
- **No install, build, package manager, bundler, framework, game engine, backend, account or network service.** Use classic ordered `<script src="…">` tags with relative paths; no ES-module loader, `fetch` of data files, CDN, analytics or remote fonts. Support `file://` as well as an arbitrary static-host subdirectory. For LAN play, `python3 -m http.server 8000` from the project root is sufficient.
- Use HTML/CSS for screens, panels and dialogs, Canvas 2D for world views, figures and maps, inline vector paths for command icons. Generate artwork in code; ship no image, model, music or sound assets. The game must work with the network disconnected.
- Target recent Chrome, Edge, Firefox and Safari, including iPadOS/iOS Safari 16+. Keyboard and mouse on desktop and touch-only play in both orientations are first-class. Saves are local to the browser/device/origin, not files downloaded by the player or cloud saves.

## 2. Runtime layout and boundaries

Use the following load order. A “module” in game data means an **adventure**, not a JavaScript module. The scripts share a classic-script scope; use namespaces/closures for subsystem internals. Keep data definitions separate from rules, and both separate from drawing and input.

| Order / file | Responsibility and contract |
|---|---|
| 1 `js/rules.js` | Dice, races/classes, ability modifiers, THAC0, saves, spell slots, turning, thief skills, trap definitions, PC creation, XP and derived stats. Calculate from current equipment/effects rather than storing stale sheet values. |
| 2 `js/data.js` | Base `ITEMS`, `SHOPS`, `SPELLS`, `MONSTERS`, `MAPS`, `QUESTS`, rumors, item lookup and six pre-generated heroes. Includes Emberfall, the Vaults, the Emberwild and the watchtower. |
| 3 `js/modules.js` | Extend the registries for Thornwick, Coldharrow and Ravenmoor. Define `MODULES`, the saga `CAMPAIGN.order`, service names, tier kits and story links. |
| 4 `js/monsters.js` | Wider creature catalogue; construct stat blocks from HD and overrides. Source for generated encounters as well as the bestiary. |
| 5 `js/wilds.js` | Authored `thorn_wild`, `cold_wild` and `rav_wild` region maps, encounters, rumors and site behavior data. |
| 6 `js/treasure.js` | Enchanted item catalogue, wearable-effect helpers, weighted treasure tables, seeded `Treasure.roll(rng, characterLevel, kind) → {gold, items}`. |
| 7 `js/adventures.js` | Build high-level kits, band-specific shop lists and all fifty adventures **once at load**. Emit ordinary registry entries and assemble `CAMPAIGNS`. |
| 8 `js/figures.js` | Shared procedural `drawFig`, `figForChar`, `portrait`; used on sheets, in encounters, in the raycast view, on the overland map and in combat. |
| 9 `js/view3d.js` | `View3D.init/prepare/render/minimap/figTex`: build textures, pack geometry, raycast a view, project billboards, draw grid maps. No game-rule side effects. |
| 10 `js/ui.js` | DOM helpers, modal stack, command bar, party drawer, character creation, roster, sheets, shops, services, help and slot/menu dialogs. |
| 11 `js/combat.js` | `Combat.start(spec)` returns a Promise of `{result, xp, left}` (result is `win`, `lose` or `fled`); owns the tactical board, turn scheduler, AI, targeting, spells, hit resolution, temporary effects and animation. Expose whether combat is active and dispatch combat keys here. |
| 12 `js/overland.js` | `Over` region painter, camera, reveal/minimap/full-map; `wildMove`, travel time, camping, encounter negotiation and site visits. Share the battle, shop and loot systems with first-person play. |
| 13 `js/campaign.js` | Create/import company state, apply starting kits, select modules, resolve service names/stock, carry a company between adventures and finish modules. |

| 15 `js/map.js` | Map marks, hover hit testing, discovered-place labels and legend, click minimap to open full map. |
| 16 `js/bestiary.js` | Key monster definitions by ID, record first sight/battle/kill, draw encounter cards and the discovery-gated bestiary. |
| 17 `js/navpad.js` | Remembered on-screen direction pads, pointer repeat/cancel and placement toggle. |
| 18 `js/watch.js` | Locate live set encounters on a grid, check line of sight, surprise/stealth, hearing and guarding treasure. |
| 19 `js/game.js` | Own campaign state, current exploration runtime, save/load, map entry, movement/arrival events, traps, camping, title/assembly screens, global input and bootstrap. |

On `DOMContentLoaded`, initialize the 3D and overland canvases, connect overland step input, initialize minimap, party drawer and nav pad, then show the title. Allocate large regional images on entry, not one bitmap for each of the 54 regions at boot. Only the active view should receive game input.

### World definitions vs. saved state

Use stable string IDs for all cross-references. A save is a small mutable overlay on definitions rebuilt at startup. Do **not** serialize DOM nodes, textures, animation timers, the current modal, the tactical board or a copy of the generated world.

| Definition | Required shape and interpretation |
|---|---|
| Adventure | `code, name, lvl` (starting level), `levels:[min,max], diff:1..4, size, length, hub, maps:[], gold, next, quests:[], side:[], final, names, rumors, blurb, intro, hint, victory, lose`; optionally `shops`, `generated`, `tier`. `names` supplies place names, giver and trainer; apply defaults by service ID. |
| Local map | `name, grid:string[], wall, floor`, optional `ceil, outdoor, facades, safe, arena, start:{x,y,dir}, locs, ev, traps, stairs, exit, keyItem, lockText, wander`. Coordinates are zero-based, `x` right, `y` down. Transitions specify **destination map and arrival coordinates**, not just a level number. |
| Event | Lowercase map letter indexes `ev`. `text`: description and optional items/deed. `enc`: `mons:[[monsterId, countOrDice],…]`, text and optional hidden/sight/surprise, arena, gold, items, quest. `chest`: text, gold, item IDs and optional guard, trap or quest. Persist completion under `mapId:letter`. |
| Overland map | `overland:true, grid, sites` keyed by site character, optional `enc`, `encRate`, `colors`, `rumors`, `travellers`. Site has `name, icon` and can be `home`, `road`, `safe`, or carry `enter`, `fight`, `holy`, `heal`, `hamlet` or plain `text`. |
| Commission | `name, lead, goal, offer, done, gold, xp`; optional `side`, `needItem`, `reveal`. Separate field accomplishment (`flags['q:'+id]`) from acceptance/payment (`quests[id]`). |
| Monster | `name, hd, hp` (dice or fixed), `ac, mv, thac0, atk:[damage,…], size, ml, xp, gold, tags, fig`; optional `lore`, leader, ranged attack, caster level/list, undead rank and special traits. E.g. `4.3` HD means 4d8+3, `0.5` means 1d4, `0.9` means 1d8−1. |
| Item / spell | `item(id)` resolves equipment, consumables, valuables, `scroll:<spellId>` or `deviceId#charges`; retain the full instance ID through all transfers. Spell metadata: `name, c, l, tgt, range, desc` (`c` is `M` or `C`) and optional `r` (radius), `len`, `camp`, `explore`, `corpse`. Every usable spell/item has a rules handler. |

**Persistent `G` (version 2):** `module`, `done: moduleId[]`, `won`, `roster: Character[]`, ordered `party: characterId[]`, pooled `gold`, `map,x,y,dir`, `time` in minutes since day 1 midnight, `march` in minutes since rest. `flags` holds event/deed, sight/hearing, site and trap progress; `mods[mapId]['x,y']` holds replacement cells; `seen[mapId]` is a row-major exploration mask; `quests` tracks commissions. Create `ground[mapId]['x,y']:itemId[]`, `journal[]`, `bestiary{}`, rumor cursors and `meta` as needed. For a new game, start at the hub's `start`, north (`dir:0`) at day 1 **08:00**, no selected party, no completed content.

A **Character** has unique `id`, `name,race,cls,align,color`, six scores plus `strx`, `lvl,xp,hp,maxhp`, `eq` (slot → item ID or null), `inv` (array allowing duplicates), `spec` or `foe`, `book` (mage spells), `prep` and `mem` (spell ID → copies), `fx` (e.g. armor capacity, strength expiry), delayed `poison`, `dead`, `layUsed`; `lost` distinguishes a failed raising. Resolve party IDs against the roster in marching order, never maintain a second mutable copy of a hero.

**Transient runtime:** keep an exploration object (`X`) with current map definition, modified cells, prepared renderer map, sprites, interpolated camera, busy/interaction lock and at most one pending movement. Keep watch/AI caches and combat state separately. Entering/loading a map reconstructs these from definitions + `G`. A redraw must never roll an encounter, pay a reward, consume time or advance a turn.

## 3. Player flow, party and interface

1. **Title** (`#title`): glowing gold “Emberfall”, subtitle “The Emberwild Saga”, drifting embers, New Game, Continue (newest timestamp among all slots; show location/time), Load Game and How to Play. Disable Continue/Load when no usable save exists.
2. **Choose an Adventure** (`#campaign`): tabbed cards, selected card outlined. Show code, title, recommended levels, difficulty name and four pips, size, estimated duration, blurb, completion mark, counts derived from the maps (areas, set battles, wilderness sites, chest treasures, commissions). Select a new company or bring one from any occupied save. Default to E0. Allow Back and Assemble the Company.
3. **Assemble Your Company** (`#assembly`): waiting roster and active party side by side, portraits, abilities, HP/AC, class/level and pooled funds. Add/remove, move forward in marching order, create, and delete waiting heroes. Begin is disabled with zero members; Add is disabled at six. The first three able members deploy in front, next three behind. Beginning shows the adventure intro, logs the local hint, records arrival and autosaves.
4. **In play** (`#game`): one HUD above `#viewport/#stage` with the mutually exclusive `#view3d`, `#overCanvas`, `#combatCanvas`. Show party toggle with one colored health pip per member, current location, facing and a description of what is ahead (or terrain/site and march status), day/time and pooled gp. Beneath: contextual icon `#cmdbar`, one-line `#cmdhint`, scrolling `#log` and `#minimap` (500×420 backing canvas). Color-code good, bad, spells, round headings and secondary text; retain the last 250 log lines. This is a transient log, not the journal.
5. **Party drawer** (`#party`): slides in from the left, not a permanently reserved viewport column. Portrait, name, race/class/level, training-ready indicator, HP bar and numbers, AC, dead/unconscious/poisoned state, filled vs hollow pips for ready/spent spell copies per level and lay on hands, armor/strength/venom indicators, summary of what rest restores. Do not rebuild portraits on every step when displayed values have not changed.
6. **Character sheet:** show identity, status, XP vs next threshold, all abilities and actual modifiers, HP, AC, THAC0, attacks/damage, movement, five saves, class and racial features with *this character's* numbers (including whether gear qualifies). Show equipped slots, pack, items on this square, spell preparation/ready counts and eligible out-of-combat casts. Allow marching-order change, equip/remove/give/drop/take, use/read/learn as applicable. No sheet-based extra actions in combat.
7. **Dialogs/menu:** overlay stack with scrollable bodies and visible action bars; a prompt for a required choice must wait for a valid answer. Never turn an Enter used to confirm into a world step. Menu: Map, Journal, Bestiary, Touch Controls, Save, Load, Campaign, How to Play, Quit to Title, Resume. Campaign travel is available **in a safe town**, not from a dungeon, the road or battle. Help must explain the actual controls, surprise, travel, combat, memorization, training and campaigns.

### Input contract

| Context | Inputs |
|---|---|
| First person | W/↑ forward, S/↓ back, A/← and D/→ turn 90°, Q/E strafe left/right; F search, R camp. Forward into a service door opens it; forward into the gate offers travel. |
| Wilderness | W/A/S/D or arrows are absolute N/W/S/E; Q/E/Z/C are NW/NE/SW/SE. Click/tap the landscape to take **one** step toward the point. Step onto a site to visit; Enter/Space or Visit invokes it again. R camp. |
| Exploration, either view | P/HUD button toggles party, 1–6 open sheets, M or minimap opens full map, J journal, B bestiary, Esc menu. Provide buttons for play without keyboard. |
| Combat | Click/tap a blue tile to move, enemy to attack; WASD/arrows step or attack in a cardinal direction. C cast, T turn undead, H hide, U use item when offered. Select a valid target or cancel via Esc/right click. Space/Enter ends turn. Q starts Auto-Battle; offer Stop Auto to return control. P may show status; Esc is **not** a save menu here. |
| Dialogs / touch | In a dialog only its actions apply: Esc closes if closable, Enter activates an enabled primary action, do not intercept typing in inputs/selects. ✥ on the view or Touch Controls in the menu cycles **off → right → left → both → off**. Default to right for coarse pointers, off for mouse. Local pad: 2×3 turn/forward/strafe/back buttons; wilds: 3×3 compass with Visit in the middle. Hold to repeat (~60 ms), stop on release/leave/cancel, do not repeat Visit. Hide the pad in combat. |

### Company creation

- Supply six equipped **waiting** heroes without any rolls or purchases required to field them: **Aldric Thorne**, human fighter (long sword specialist, chain + shield); **Seraphine Vale**, human paladin (broad sword, chain + shield); **Borin Stonehand**, dwarf cleric (mace, sling, chain + shield); **Lyra Windwhisper**, half-elf ranger (goblins, long sword, studded leather, long bow); **Pip Quickfinger**, halfling thief (short sword, leather, sling); **Elowen Starfall**, elf mage (staff, darts). They are not automatically all selected.
- Custom creation: require a trimmed, nonempty name (up to 20 characters), offer a race-specific suggested name, race, legal class and alignment, color swatches, fighter specialization or ranger species enemy, live portrait/stats preview and reroll. Roll STR, DEX, CON, INT, WIS, CHA **in order** as 4d6 drop the lowest. Apply racial adjustments, check raw racial bounds and adjusted class minima, retry with a bounded fallback. At STR 18 a warrior gets a percentile exceptional-strength roll (100 shown as 18/00). First-level HP = full class hit die + CON modifier, minimum 1. Custom recruits contribute rolled class gold to the pooled purse and normally buy their own gear.
- Advance new rosters to the module's starting level. Class-specific kit thresholds: 3, 5, 9, 13, 17. Pregens receive the prescribed upgraded gear and pack contents. Newly made higher-level heroes get applicable magic/silver gear and kit supplies plus extra gp (150, 500, 2,000, 6,000, 12,000 respectively); do not issue a fresh kit to an imported veteran. Compensate mages with a new eligible spell per level gained.

## 4. Rules and resources

Use integer dice including `NdS`, `NdS+K`, `NdS-K` and fixed amounts. Separate nondeterministic play rolls from the content generator's seeded RNG. Display rolled attack totals/targets and reasons why a command cannot be used; a player should be able to tell whether they missed, the target saved, or their weapon had no effect.

### Races, classes and advancement

- Human: any class, MV 12. Dwarf: F/C/T, +1 CON/−1 CHA, MV 10. Elf: F/R/M/C/T, +1 DEX/−1 CON, MV 12. Gnome: F/C/T, +1 INT/−1 WIS, MV 10. Half-elf: F/R/M/C/T, no adjustments, MV 12. Halfling: F/C/T, +1 DEX/−1 STR, MV 10. Implement racial ability limits, thief adjustments and actual combat/exploration differences. Examples: elves/half-elves resist Sleep (90%/30%) and notice secret doors; elves have sword/bow bonuses and resist ghoul paralysis; halflings favor slings/thrown weapons; dwarves/gnomes have bonuses against particular humanoids and defenses against large foes. Dwarves, gnomes and halflings get CON-based magic save bonuses, dwarves and halflings also vs poison.
- Support all nine alignments, filtered by class. In this table XP is the **first** level-up threshold and gold is rolled in tens of gp. Use the full group save, class XP and caster slot progressions through level 20 (reference tables: `js/rules.js`), not one linear XP curve.

| ID | Class; HD | Minimum scores; prime requisite(s) | Level 2 XP; starting gold roll | Distinguishing mechanics |
|---|---|---|---|---|
| F | Fighter; d10 | STR 9; STR | 2,000; 5d4 | Pick a melee weapon family. With it: +1 hit, +2 damage and an extra half attack/round, including enchanted variants. |
| P | Paladin; d10 | STR 12, CON 9, WIS 13, CHA 17; STR+CHA | 2,250; 5d4 | Human lawful good only. +2 saves, adjacent evil foes −1 to hit, lay hands for 2 HP/level once per rest; turn as cleric level−2 from level 3. Limited priest spells from level 9, cast at `clamp(level−8,1,9)`. |
| R | Ranger; d10 | STR 13, DEX 13, CON 14, WIS 14; STR+DEX+WIS | 2,250; 5d4 | Good only. Choose goblin, orc, kobold, undead, giantkin or troll: +4 hit and +level melee damage vs matching tags. With light/no armor, one-handed weapon and no shield, add one 1d6+STR off-hand strike/round. Helps with surprise/evasion. |
| M | Mage; d4 | INT 9; INT | 2,500; 1d4+1 | Spellbook, no ordinary armor/shield; dagger, staff, darts or sling. Learn from scrolls and training. |
| C | Cleric; d8 | WIS 9; WIS | 1,500; 3d6 | Blunt weapons, armor/shield, priest spells, wisdom bonus slots, spell failure below WIS 13, turning. |
| T | Thief; d6 | DEX 9; DEX | 1,250; 2d6 | Not lawful good. Light armor, Open Locks, Find/Remove Traps, Move Silently, Hide in Shadows, Hear Noise; scale skills by level, race, DEX (cap 95%). Backstab +4 hit; multiply base weapon dice ×2/3/4/5 at levels 1/5/9/13. |

- **To hit:** with `n = level−1`, THAC0 is `20−n` for warriors (F/P/R), `20−2*floor(n/3)` for priests, `20−floor(n/2)` for thieves, `20−floor(n/3)` for mages. Need `d20 + hitModifiers >= THAC0 − targetAC`. Natural 1 misses and natural 20 hits; a helpless target is automatically hit. Lower AC is better: start at 10, substitute armor AC less enchantment, apply protective magic, usable shield (1 + enchantment) and DEX defense. Negative AC is valid. STR affects melee hit/damage/forcing doors; DEX affects missiles and AC. Select weapon damage vs S/M or L/H/G. Use missile rate of fire; base warrior melee attacks go 1 → 3/2 at level 7 → 2 at level 13. Implement half attacks as extra attacks on even rounds, not fractional damage.
- **Saves:** d20 at/above table target for (1) paralyzation/poison/death, (2) rod/staff/wand, (3) petrification/polymorph, (4) breath, (5) spell. Apply group/level, race, paladin, relevant WIS mental adjustment, wards and gear. E.g. level-one fighter base targets in order are 14/16/15/17/17. Monsters generally save as warriors by HD; magic resistance can count as a successful save.
- **Progress:** award XP only to surviving PCs in the active company. Apply +10% (floor) when **all** prime requisites are ≥16. Cap awards so one cannot skip two levels without training (cap at one below the threshold two levels ahead, where applicable). Training costs `100 × current level` gp **per PC** at the training hall. Roll class HD + CON (min 1) through level 9 for warriors/priests or 10 for thieves/mages, then gain fixed +3/+2/+2/+1 HP respectively (warrior/priest/thief/mage). Set readiness, do not level up automatically at victory. Level drain can remove levels, HP and invalid preparations; draining a level-one PC kills them.

### Spells

Distinguish **known** spells, copies **chosen for next rest** (`prep`), and **castable now** (`mem`). A mage starts with Magic Missile, Sleep, Armor, Burning Hands and Shield. Priest knowledge depends on list/slots, not a book. Auto-fill empty slots with useful defaults; allow `+`/`−` on the sheet per spell level, not above capacity. Rest copies `prep` into `mem`. Casting consumes a ready copy, even on priest failure. Changing preparation must not grant an immediate cast. Rings of Wizardry can double slots; paladins use their own table and subset, not the whole cleric list. A mage may consume a wizard scroll for one INT-based chance to learn; **disable Learn for an already-known spell**, without destroying the scroll.

Implement the following lists (levels are **spell** levels, not character levels):

| 3 | Fireball, Lightning Bolt, Haste, Hold Person, Slow, Dispel Magic, Vampiric Touch | Prayer, Dispel Magic, Remove Paralysis, Magical Vestment, Cause Blindness, Cure Blindness |
| 4 | Ice Storm, Stoneskin, Fear | Cure Serious Wounds, Neutralize Poison, Cause Serious Wounds, Free Action, Protection From Evil 10′ Radius |

Implement targeting (enemy, ally/touch, self, party, area, cone, line, exploration only), range, previews, dice/HD or HP limits, saves, duration and side effects; do not make these names aliases for generic damage. For example:

- Magic Missile automatically hits with `min(5,ceil(casterLevel/2))` missiles of 1d4+1; Shield negates it. Sleep spends a 2d4 HD pool weakest first, can affect friends, not undead. Damage wakes sleepers. Fireball reaches 12 squares, radius 2.3, up to 10d6, save for half, **including allies**. Lightning Bolt follows a line until obstructed. Stinking Cloud persists on squares, calls for repeated saves and makes victims stagger out. Haste doubles movement/attacks; Slow can undo it. Mirror images intercept attacks, Stoneskin negates a limited number of blows.
- Draw a distinction between stun/hold, web, nausea, blindness, slow, fear, silence, invisibility, poison and outright death; respect free action, immunities, magic resistance, dispelling and counters. Power words use HP thresholds; elemental protections reduce matching damage. Healing includes 1d8 light, 2d8+1 serious, 3d8+3 critical, and Heal restores all but 1d4 missing HP and treats afflictions.
- Knock is a locked-door option, not a combat attack. Cures, poison removal, Armor (AC 6 field expiring after 8+level damage taken), Strength (1 hour/level), Raise Dead and Resurrection have sheet/out-of-battle uses. Raise Dead requires CON survival, returns at 1 HP with −1 CON; failure leaves the spirit beyond ordinary recall. Resurrection restores even a lost companion at full HP.

### Equipment, loot and town services

- Equipment slots: melee, missile, armor, shield, two rings, cloak, boots, gloves, belt, neck, charm. Item type codes: `w/r/a/s/g` for primary equipment; `m` worn, `p` potion, `d` device, `x` scroll, `k` ability book, `v` valuables, `q` quest item. Equipping swaps previous gear into the pack. A two-handed weapon removes a shield to the pack; reject equipping a shield while it is wielded. Unarmed fallback is a 1d2 fist. Enforce class restrictions, use base weapon IDs for specialization. Include silver and enchanted weapons for enemies immune to ordinary steel.
- Magic is functional: bonuses to hit/damage/saves/AC; tagged favored enemies, special slaying and disruption weapons; bracers, protective rings/cloaks, giant-strength gear, regeneration, speed, free action, invisibility, poison/drain wards, wizardry rings; healing/antivenom and short combat buffs; single-use books increase an ability by one up to 18. A spell scroll can be read in battle by the appropriate class; protection scrolls ward the party against a monster tag. Devices cast listed powers at their own level; choose power for multi-spell devices (Wonder is random). Decrement charges in the item ID, remove the exhausted device; certain healing devices work at camp. Descriptions, prices, sheet effects and combat behavior must agree.
- Treasure generator: tier `clamp(ceil(characterLevel/4),1,5)`; roll category then weighted entry at or below treasure tier. Category weights: potions 20, scrolls 15, rings 5, devices 5, miscellaneous 15, armor/shields 15, swords 11, other weapons 14. Favor newer tiers at depth. Generate ordinary chests, guarded/hidden caches and boss hoards in increasing value (coin scale about `25 × level^1.45` times random 0.6–1.4, multipliers 1/2/6 respectively, rounded to 5 gp). Caches have magic; hoards have multiple magic rolls, can reach one tier higher, include potions and valuables. Return deterministic contents when given the same seed. Pre-generate stash contents; declining/reloading must not reroll the stash.
- **Ground is part of the world.** Dropping removes that instance from its owner's pack and appends it under current map and square. Display a loot sprite/bag and map marker. On return offer Take everything (first conscious carrier) or leave it; on the sheet take individual items. Delete empty piles. Gear, including partially used devices, persists across map transitions and ordinary saves. Quest items may be given to another member but not dropped or sold.
- **Shops** (armory/apothecary or village general store): choose buyer, show class usability, prices and shared funds. Deduct cost, place in that member's pack, auto-equip usable gear if slot vacant. Sell *pack* gear for floor(half price), gems/jewelry for full worth. No purchase without funds. Larger generated towns use level-band shops: mundane and silver stock plus eligible items from lower treasure tiers (band `t` sells through tier `t−1`, recent two tiers for arms); exclude rare weight <4, books and Rod of Resurrection. Apothecaries stock potions, protection/spell scrolls and charged devices as appropriate; spell-scroll top levels 1/3/5/7/9 across bands (latest four levels, exclude exploration-only spells except Knock). E2/E3 use band-2 stock. Rare top-end rewards remain finds.
- **Inn:** 1 gp per party member per night, wake next day at 07:00, +3 HP each living PC, clear march fatigue/temporary buffs, spend remaining cures on the wounded before re-memorizing, restore spells and lay on hands. Rest once or repeat until healed, out of funds or 60 nights. Permit roster changes/recruitment, require a conscious member before dismissing that dialog, allow saving. **Temple:** 20 gp Cure Light, 60 Cure Serious, 80 Neutralize Poison, 400 Raise Dead; only show applicable services and disable unaffordable ones. **Tavern:** 2 gp for a round and a local rumor recorded in Notes. **Hall** handles commissions; **training** handles eligible paid level-ups, including mage's choice of one unknown spell of an accessible level.

## 5. First-person exploration and encounters

### Grid, arrival and time

Local map legend: `#` wall; `H/B` timber/brick building; `1`–`9` service doors resolved by `locs`; `G` gate; `.` floor/street, `,` grass; `T` tree, `F` fountain (both solid billboards); `D` ordinary door (opaque to sight, step through it); `L` locked door; `S` secret door (appears as wall until discovered); `<`/`>` stairs; `a`–`z` walkable event sites except a live band occupies its tile. Outside the grid is solid. Do not use the wilderness symbol meanings on a local map.

- Keep integer `(x,y,dir)` authoritative; camera rests at `(x+.5,y+.5)`, angle `(dir−1) × π/2`, directions 0/1/2/3 = N/E/S/W. Smoothly interpolate a 90° turn (~140 ms) or one-tile step (~170 ms). Buffer at most one further command while animating; cancel held-input repeat on release. Use `requestAnimationFrame` plus a finish-once timeout fallback. Do not queue steps through a choice, transition or encounter.
- One completed step costs **1 game minute**; turning costs none. Tick timed effects; reveal 3×3 around the party and along the facing direction up to seven cells plus sides, stopping at opaque cells. Store revealed squares per map. Mention notable squares ahead and equipment underfoot in the HUD.
- On arrival, check passive elven discovery, stairs/return points, floor trap, ground pile, monster watch, letter event, door listening and then map-specific wandering roll. Respect outcomes that interrupt the sequence. Stairs change maps immediately; a gate offers a choice; only forward bump opens a service. Entering a map must not recursively trigger its arrival stair. Apply modifications to a copy of the definition, never destroy the base grid.
- **Locks:** offer matching key from party inventory, best thief's Open Locks %, strongest conscious member's STR force roll on d20, a memorized Knock, or leave. Thief pick attempt costs 10 minutes and is once per lock/thief/level; forcing costs 10 minutes and failure can draw wanderers (25% where applicable). Knock spends one ready copy. A successful lock or secret changes to ordinary `D` permanently for this save.
- **Search (10 minutes):** check four neighboring cells. Ordinary search finds secrets on 1-in-6 per able PC, elf/half-elf 2-in-6; those races also get 1-in-6 passing discovery. Use thief Find/Remove Traps for detection and a separate disarm check; anyone may spot floor traps, dwarves are better. `found` means mark trap on map and safely step around; `off` means disabled or already sprung. On stepping into an unknown trap a thief may detect/disarm just in time. Pit/spear hit the front, darts/blade hit one; falling stones/fire rune/gas hit all with a save for half (breath or poison). Scale single-target damage about `max(1,round(level/2))d6`, group about `max(1,round(level/3))d6`. Chest traps are separate and resolve upon opening.
- **Chests/text:** text can grant an item/deed once. Offer open/leave, resolve any guardian first, then trap, distribute items to a conscious carrier, add gold and split 1 XP per gp among nondead active PCs. Set the completion flag and remove the chest sprite/marker only on collection. No repeat rewards on revisiting. Authored wandering tables supply per-step chances and dice groups independent of set encounters.
- **Camp:** no sleeping on safe town streets; direct player to inn. One uninterrupted field rest is 8 hours, +1 HP per living member (extra 10 with regeneration), restored chosen spells and hands, reset march, process expiring effects/venom. If injured, offer **Rest until healed**: spend remaining prepared cures and daily hands on the worst hurt before *each* rest, cap at 14 rests, stop on interruption. Dungeon rest with wanderers: 35% chance of attack per attempt (healers may already have spent resources). Do not give full-rest benefits for an interrupted attempt.

### The watch: visible groups, not just random battles

Represent each uncleared set battle as **one stationary band on a specific tile** with a billboard of its leader or first creature. Block stepping into it; a bump challenges it. Cache counts on first meeting that visit. Nonhidden groups can be glimpsed at 9.5 tiles (remember as seen and mark on explored map); they notice the party within 6.5 tiles unless overridden. Test actual line of sight: opaque walls and doors block; endpoints do not, so standing *in* a doorway works; no peeking through the corner where two walls meet. Hidden bands lie in ambush, invisible until sprung at about 1.5 tiles or disturbed at treasure. Nearest eligible group reacts first.

Roll surprise on d6 per side. Normally 1–2 surprises; light-armored elf/halfling and having heard this band improve the party's chance of surprising it; a ranger reduces the party's own risk. An ambush is harder to notice and cannot itself be surprised. One side surprised loses the first round; both or neither means no advantage. If the company spots an unaware group, offer **attack with a free round, back away (if just moved), hold still**, and, if possible, **creep up**: Move Silently preserves the surprise round; additional Hide in Shadows starts the thief hidden for backstab. Waiting is not immunity: each further step risks notice. After fleeing, suppress immediate re-engagement until contact is broken. On victory clear the band, apply event deed/loot, rebuild sprites/marks and autosave.

A thief automatically listens at an adjacent door once per door per visit (Hear Noise); if there is an unseen band on the other side, report a clue appropriate to the creature and remember it was heard. Reaching for a chest with a named live guard, or a nearby live band in sight of it, starts a fight before any loot. Seen/heard/cleared knowledge is persistent; the momentary unaware/calm state is not.

## 6. Wilderness travel

Render a scrolling top-down painted region, north up, with the leader as party token. **One tile = one mile**. The eight directions are absolute. `^` mountains and `~` river are impassable; use bridges. Capital site markers (distinct from reserved terrain symbols) dispatch site visits; prompt on arrival or Visit while standing there.

| Ground | Symbol | Time multiplier | Base encounter chance/hour | Tactical theme |
|---|---|---:|---:|---|
| Grassland | `.` | 1 | .05 | plains |
| Road / bridge | `=` / `+` | .5 | .035 | road |
| Forest | `T` | 2 | .08 | forest |
| Hills | `n` | 2 | .07 | hills |
| Fen | `%` | 3 | .09 | swamp |

Use the slowest **conscious** PC's MV. Charge `round(600/(2 × MV) × destinationCost × diagonalFactor × fatigueFactor)` minutes per successful step; diagonals 1.4, weary factor 1.5 once `march >= 600` minutes. An MV 12 company covers 24 grassland miles in ten hours; a party with an MV 10 dwarf needs 30 minutes for one grass mile, 15 on a road. Increment both time and march, warn on reaching ten hours, tick timed effects. An ordinary site tile costs one grassland mile and invokes its site instead of rolling an encounter.

- Start knowing roads and the ground near home. Track currently visible vs previously explored vs unknown; base radius ~4.2 by day or 2.2 by night, +2 on hills, −1.2 in woods/fen. Night before 05:30 or from 20:00. Show discovered site names, compass, day/dusk/night tint and hover terrain/cost. Only visible/revealed information belongs on either map.
- Step encounter probability `1 − (1 − baseHourly × regionRate × nightFactor)^(minutes/60)`, night factor 1.5. Use terrain-weighted, day/night-filtered tables, regional overrides and numbers appearing as fixed/dice. Merchants offer country goods; travelers/pilgrims pass on local rumors.
- Hostile encounter: describe distance and group with portraits. Each side surprise on 1–3/d10, enemies up to 5 with a ranger off-road. Party surprised alone → enemy first round. Spot them first → ambush or slip away. Otherwise fight, evade, or parley if allowed. Evasion chance `clamp(50 + 6×(partyMV−slowestEnemyMV) + 10 if forest/hills + 10 if ranger, 5,95)` percent; guaranteed if unseen; successful evasion costs 30 minutes. Parley uses best CHA and `2d10 + reaction`; bandits may negotiate a gp toll (9+), other intelligent patrols may allow passage (13+), refusal/failure leads to battle. Use terrain arena and night shading.
- Sites support choices to enter town/dungeon (possibly gated by deed), one-time fights with approach/scout/withdraw, cache and post-victory description, blessings with first-visit XP, sanctuaries for safe camps, hermit healing all living PCs/removing poison once per seven days, hamlet beds/trade/gossip/save and descriptive landmarks. Some clues/commissions reveal a destination on its own map. Place flags in a region-specific namespace. Outside a refuge, wilderness camp checks for hostile interruption over the eight hours; otherwise apply the common rest rules.

## 7. Tactical combat

**Battle setup.** Suspend exploration/input, hide its canvas, show an encounter portrait per creature kind (count, kind, New badge), then run an asynchronously resolved battle. Build a **14×10** square grid in isometric projection, 10 ft per square. Front rank starts at x=3, second rank x=1 near the left center. Enemies on the right with melee nearer, ranged/casters farther; roll HP for individuals and distinguish repeated monsters by number. Generate obstacles in the intervening space; indoor themes include street, dungeon, cave, barrow, crypt, keep, pit, sanctum. Outdoor battlefields use road, grass, trees, rocks, brush or reeds, not the overworld's mile scale.

**Round loop:** increment round; roll individual initiative anew: d10 + wielded melee weapon speed (PC) or size modifier (monster), haste adjustment, tie break; low acts first, slow monsters last. Honor surprise for round one. A conscious actor gets movement then attacks or a special action. Await each player choice/AI animation before continuing. Recheck victory/defeat after actions, tick effects/regeneration at round end, bleed unstable victims once each round. Battle-local effects/rounds are distinct from the minute-based world clock.

- Compute reachable tiles and predecessors with a weighted flood over eight neighbors. Normal budget `2 × ceil(MV/2)` half-square units; cardinal cost 2, diagonal 3, no cutting corners through obstacles or sharing occupied cells. Highlight reachable tiles, permit partial moves before acting. Leaving an able enemy's reach provokes a free melee attack (+2), at most once per threat per mover's turn; hidden movement avoids it. Stop walking if downed or immobilized. Attacking consumes remaining movement; allow remaining attacks only.
- Adjacent (including diagonal) = melee. Beyond adjacency require a readied missile weapon, clear line past obstacles, range and **no adjacent foe**. Data missile range bands are in 30-ft units (×3 squares); penalties 0/−2/−5. Roll attacks and damage per §4, using proficiency/specialization, racial and enemy tags, weapon magic, size, wards, statuses. E.g. skeletons halve non-blunt damage; silver-only monsters accept enchanted or silver hits, magic-only require enchantment. Log rolls and display miss/no-effect/damage separately.
- Offer legal contextual actions: **Cast**, Turn Undead, Lay on Hands (self/adjacent ally), thief Hide, Use Item, Bandage, Flee at an edge, End Turn, Auto-Battle. Show why an action is unavailable. Thief may hide if no foe adjacent; invisible/hidden units are not AI targets, revealed on striking/casting; backstab if hidden or an able ally stands directly opposite the target. Turn once per eligible PC per battle: d20 vs undead-rank/cleric-level table, up to 2d6 creatures weakest first, either no effect, flee, or automatically turn/destroy at high levels.
- Spell selection shows ready counts and descriptions. Valid squares/units and hover preview must match resolution (range/line of sight, radius, line stopped by obstacles, directed cones). Confirming consumes a spell or item/charge; canceling does not. A caster **hit earlier in this round** cannot cast from memory, nor can a silenced caster. Potions can be administered to self/adjacent ally. Held/asleep creatures can't act; implement ongoing clouds, damage over rounds, temporary HP, dispels and expiration. Do not let an extra click act for the next unit.
- Monster turns use finite spell lists, score area targets by foes versus friendly fire, use viable buffs, gazes or breath with appropriate cooldown/uses, shoot with clear line, else find a reachable melee position and strike (including multiattacks). Implement special traits: poison (delayed world time, roughly 16–30 minutes to onset), paralysis, level drain, rust, petrification, regeneration, resistance, special weapon requirements. Racial resistances and protective items must change outcomes. Auto-Battle handles player turns with tactical movement and weapon attacks; it is not an instant win or an optimal spellcasting solver.
- On loss of leader or reduction to half the enemy force, check remaining monsters' morale (2d10 > morale breaks; 20 fearless). Broken/turned foes path to an edge and leave. PCs flee **individually** from an edge. At 0 through −9 HP a PC is down and loses 1 HP/round until stabilized by adjacent bandage or healed. At −10 dead. If no standing PC remains, result is defeat unless someone escaped. End a stalled battle after ~150 rounds. Remove battle-only state/temporary HP and stop the animation loop on exit.
- **Victory settlement:** XP for actually slain/destroyed monsters + recovered gold (rolled per enemy plus encounter gold), floor-divided among nondead party members, then individual XP modifiers/cap. Add gold once, fixed event items to first conscious carrier; surviving downed PCs return at 0 HP. Report rewards and who can train. On flight restore prior exploration position, mark downed companions left behind dead, no victory rewards or clearing flags. On loss show module-specific fallen-party dialog with Load/Title. On return redraw correct exploration view, commands, party and map.

### Generated adventures: a repeatable content pipeline, not “random dungeon” mode

Use IDs `adv<t>_<i>` and codes `T<t>-<two-digit i>` (both indices one-based). Generate at startup in stable tier/index order so a save always refers to the same doors, bosses, items and quests. Link each `next` to the next module in its band, last to the next band's first, final T5-10 to null. Selection is not gated on playing them in this order.

## 10. Saving and resuming

- Serialize `G` as JSON in `localStorage` keys `emberfall.save.auto`, `.1`, `.2`, `.3` (same prefix for every slot). Three manual overwrite slots; autosave is loadable but not a manual save target. Attach `meta:{leader,where,when,saved,ts,mod,lvl}`: leader name, map name, in-world day/time, local display timestamp, sortable real timestamp, adventure code/title, rounded party level. Continue chooses greatest `ts`, not necessarily auto.
- Autosave at meaningful checkpoints: adventure start/travel, stair/gate map changes, cleared set battles, quest items and collected treasure, commission reports/completion, inn rest and successful wilderness camp. **Not** every step; do not serialize a battle in progress. No save/load commands while combat is active. Save failure must not stop play; handle unavailable storage, missing slots and unreadable JSON.
- Load restores exact party order, HP/gear/spells, position/direction/time/fatigue, gold, events/deeds, modified doors, discovery, ground items, journals and bestiary. Clear dialogs, stale movement and battle input; rebuild the correct view/HUD/commands. Missing legacy `module` means `hollow`; derive missing `done` from `won`, initialize absent optional collections safely.
- **Load**, **import from slot**, and **travel in the current game** are different operations. Load resumes in place. New Game → Bring party creates a destination-hub state from roster/party IDs, equipment, gold, time, `done`, flags, quests, modifications and seen masks, readies survivors and allows reassembly; it does not write back to the source slot during import. In the reference this selective import does **not** copy the separate journal/bestiary/ground collections. Normal campaign travel mutates the existing state, retaining those collections. Beginning/traveling writes the shared *auto* slot as usual.
- Store drawer preference (`emberfall.party`: `1`/`0`) and pad placement (`emberfall.navpad`) separately from games. Loading a hero should not change device controls.

## 11. Implementation sequence and verification

Deliver in vertical slices so the rules, UI and data are exercised together. There is no required test framework in the runtime. Use injectable/pinned dice in rule checks, deterministic seeds for content validation, and real browser play for the canvases and input. Do not leave debug cheats or test dependencies in the player path.

| Milestone | Exit check before proceeding |
|---|---|
| 1. Static shell, rules, roster and persistence | Open from disk, create an E0 company and resume it in a playable hub. Sheet and rule functions give the same numbers. |
| 2. Authored E0 vertical slice | Implement town services, exploration/rendering, one complete cellar, watch, combat, spells, chests, quests, inn and travel. Defeat Skarrik, return to the hall and see an actual completion/next-adventure prompt. |
| 3. Regional travel and saga | All four hubs, authored regions, dungeons, side items, leaders, lairs, return routes and epilogues work; revisiting unfinished/completed work is safe. |
| 4. Full rules and generated content | Complete all levels, spells, monsters, magic items, shops, seeded modules and kits. Validate all registries on a fresh boot; start and play at both low and high level. |
| 5. Interaction, rendering and recovery pass | Finish the discovery UIs, responsive HUD/touch input, log, help, performance and failure states. Run the checks below from `file://` and a static server before release. |

### Acceptance scenarios

1. **Boot and identity:** New Game on an empty profile works offline with no missing resources or console exceptions. Continue/Load disabled; six chooser tabs and the counts in §1. Cards for E0–E3 show the §8 statistics. Two independent boots yield identical generated map strings, encounter lists, quests and chest contents. Reference fixtures: T1-01 `adv1_1` is *Othys the Many-Legged* at Crowstead (3 areas); T5-10 `adv5_10` is *The Crypt of Zuloon* at Greycross (7 areas, 6 commissions). New combats still roll fresh dice.
2. **Content integrity (automate):** iterate all adventures, not just the opening map. Assert rectangular grids, unique IDs, valid hub/start/arrival cells, service/event/site keys, reciprocally usable transitions, passable route to each objective and overland site (taking openable doors/deed gates into account). Check all quest items, monsters, spell IDs, kits, stock, drops and device powers resolve. Dungeon floors have traps/secrets; no hidden door makes the only required reward unobtainable. Generator totals include 105 dungeon floors and exactly one huge adventure per band.
3. **Creation/assembly:** reject an empty name, restrict paladin to human LG and ranger to good, disable a seventh member. Custom recruits add funds; starting a high-tier party advances, equips and prepares them. A fresh E0 company of the six pregens starts at `(9,13,N)`, 08:00, 40 gp. Aldric at level 1 with STR 17, CON 16, chain, shield, long sword has **12 HP, AC 4, THAC0 20, +2 melee hit and 3/2 attacks**. Changing gear updates stats/portrait without altering raw abilities.
4. **Exploration/loot:** in Thornwick approach service door `4` at `(14,5)` from the street to open the Elder's Longhouse. Only offered work appears in J. Descend the north brewery stairs, return to the village via `<`, no transition loop. Use the `cellarKey` from kobolds or pick/force/Knock to open `L`. Check a failed pick cannot be retried at the same level. Search near a trap and secret, verify map changes, step over a marked trap, open a guarded chest only after a win, leave and return: no respawn/repayment. Drop a charged item, leave the area, save/load and retrieve the exact item from the same square. A quest item has no Drop/Sell action.
5. **Watch/combat:** on a controlled encounter, a wall/closed door blocks sight; a visible live band blocks the tile and gains a marker; a hidden one is not advertised across the room. Test unaware attack, thief approach, failed sneak, listening and retreat. Force rolls for a normal miss, a natural 20, a helpless target, a skeleton hit with blade vs mace, an immune creature hit with ordinary vs magic gear, an opportunity strike and morale flight. Move/cast/cancel in one turn without duplicate actions; check ally hit by area spell, interrupted concentration, a hidden thief backstab and an end-of-round effect. Exercise win, edge flight, bandage/bleed and total defeat. Resume correct map after battle, no battle loop still painting.
6. **Spell economy/rest:** change a mage's prepared spell without resting: ready counts unchanged. Cast last copy; can't cast again until rest. Copy an unknown scroll on controlled success/failure; Learn disabled and scroll retained for duplicate. Use one wand charge, not one memorized copy. Check hands once per rest, delayed venom and antivenom, affordable temple raising vs failed survival. Wounded party can camp repeatedly with cures; interruption gives no free completed rest; inn deducts party size per night and restores abilities. Training requires both XP and gold, charges once and offers a mage a new spell.
7. **Wilderness:** leave gate, compare 30-minute grass vs 15-minute road for MV 10, diagonal cost and tired travel after 600 minutes. River/mountain blocks with no time cost; bridge passes. Night reduces sight and changes encounter odds/table. Exercise a friendly merchant, evade, ambush, parley/toll, a lair's one-time loot, safe shrine camp and weekly healer. In E3 the wilderness is on the main route, and the keep site refuses premature entry.
8. **Story/campaign:** perform a deed before taking its commission, then visit the hall and report it. Required retrieval item must be in an active member's pack. Reward once using the quarter-rate XP, then next main offer. Completing E0's main quest does not require the widow's ring. Travel to E2 with a lower-level company: living roster trained to ≥3, no one de-leveled, day +14 at 08:00. Revisit E0 and check flags, discovered tiles, ground piles and past journal. Travel is disabled outside safe towns.
9. **Saves/discovery:** test three manual slots plus auto. Change orientation, HP, spell copies, gear, world state, journal, bestiary and gold; save/reload and compare. Continue uses newest timestamp. Import a manual slot into another module, arrive at destination hub, then load source and verify original position. Try empty/malformed storage and legacy `hollow` saves. Bestiary after a sighting but no fight shows lore only; a fight unlocks stats, individual kills increase slain. Neither map hover nor legend should disclose unknown treasure locations.
10. **Device checks:** play on desktop, tablet, portrait phone and short landscape phone. Try keyboard-only movement, pointer picking after resize, both left and right touch pads, releasing a held button, opening a sheet, selling gear, casting, ending a turn, saving and reopening a map. The action bar and modal confirmation must remain reachable in both orientations; inputs must never move the party behind a dialog. Idle exploration should not run a continuous raycast loop.

The release is complete when a player can finish the named saga, play modules from all five generated bands, and recover the same company and world from a local save using only the shipped static files.
